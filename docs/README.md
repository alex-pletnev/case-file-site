# case-file-site — Документация

Набор справочных файлов для AI-агентов и разработчиков. Каждый файл — плотный, ориентированный на быстрый поиск: таблицы, ссылки `file:line`, минимум прозы.

## Индекс

| Файл | Содержание |
|------|-----------|
| [01-concept.md](01-concept.md) | Концепция проекта, тон, эмоциональная драматургия |
| [02-design-system.md](02-design-system.md) | Палитра, типографика, компоненты, сигнатурный элемент (красная нить) |
| [03-content-structure.md](03-content-structure.md) | Секции сайта, тексты, плейсхолдеры |
| [04-tech-hosting.md](04-tech-hosting.md) | Стек, ограничения, деплой на GitHub Pages |
| [05-photos.md](05-photos.md) | Как устроен манифест фотографий (photos.json) |
| [06-personal-content.md](06-personal-content.md) | Личные тексты — источник правды (не выдумывать сверх написанного) |
| [10-configuration.md](10-configuration.md) | Конфигурация, деплой, вспомогательные скрипты |
| [11-known-gaps.md](11-known-gaps.md) | Незакрытые вопросы, TODO, технические долги |
| [tasks/README.md](tasks/README.md) | Формат и правила task-трекера |
| [tasks/INDEX.md](tasks/INDEX.md) | Индекс задач |

## Как читать

- **Перед любой работой над проектом** → `01-concept.md` (тон и концепция), затем `06-personal-content.md` (личные тексты — ничего не выдумывать).
- **Пишешь или меняешь UI** → `02-design-system.md` + `03-content-structure.md`.
- **Работаешь с фото или манифестом** → `05-photos.md`.
- **Деплой / скрипты** → `04-tech-hosting.md` + `10-configuration.md`.
- **Новая задача** → проверь `11-known-gaps.md` и `tasks/INDEX.md`.

## Соглашения

- Пути в проекте — относительные от корня.
- Все ссылки `file:line` — актуальны на момент создания документа. При расхождении с кодом — верить коду.
- Язык: RU.
