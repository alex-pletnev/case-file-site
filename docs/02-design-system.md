# 02 — Дизайн-система

## Палитра

| Токен | Hex | Роль |
|---|---|---|
| `--cork` | `#B08356` | Пробковая доска, основной фон (с текстурой) |
| `--cork-shadow` | `#8F6640` | Тени и виньетка по краям доски |
| `--paper` | `#F6EFE0` | Полароиды, заметки, протоколы |
| `--paper-aged` | `#EAD9B8` | Состаренная бумага, стикеры |
| `--thread` | `#B3352B` | Красная нить, ключевой акцент |
| `--ink` | `#2C3550` | Чернила: основной текст, штампы синие |
| `--stamp-red` | `#8E2A26` | Красные штампы, сургуч, сердечки |
| `--pencil` | `#5A554A` | Второстепенные подписи, даты |

Фон — не плоский цвет: лёгкая шумовая текстура пробки (CSS-паттерн или
маленькая тайлящаяся текстура ≤ 30 КБ), виньетка по краям. Никакого чистого
белого и чистого чёрного нигде.

## Типографика (все шрифты — с поддержкой кириллицы, Google Fonts)

| Роль | Шрифт | Использование |
|---|---|---|
| Машинопись / протоколы | **PT Mono** | Заголовки секций, «канцелярские» тексты, даты |
| Штампы | **Bebas Neue** (uppercase, letter-spacing 0.15em) | «ВЕЩДОК №», «СЕКРЕТНО», «ВИНОВНА» |
| Рукописные подписи | **Caveat** (600) | Подписи под полароидами, заметки на стикерах |
| Основной текст | **PT Sans** | Длинные абзацы (письмо-признание) |

Шрифты подключать через `<link>` с `display=swap`, подмножество `cyrillic,latin`.

## Компоненты

### Полароид (главный компонент)
- Бумажная рамка `--paper`, нижнее поле шире (место подписи Caveat)
- Случайный поворот −4°…+4° (детерминированный от индекса, не Math.random
  при каждом рендере)
- Мягкая двойная тень (контактная + рассеянная), сверху — кнопка-пин
  (CSS-градиентный кружок со стеклянным бликом) или полоска скотча
- На тап/клик — плавное увеличение в лайтбокс (без сторонних библиотек)

### Штамп
- Bebas Neue, рамка 3px, лёгкий поворот, текстура потёртости через
  `mask-image` с шумом; появляется анимацией «оттиска» (scale 1.4 → 1 +
  короткий звук штампа)

### Стикер-заметка
- `--paper-aged`, загнутый уголок (CSS), текст Caveat, будто приколот кнопкой

### Протокол
- Лист `--paper` с «пробитыми» полями, текст PT Mono, поля вида
  «ДАТА: ___» заполнены «от руки» (Caveat поверх линии)

## Сигнатурный элемент: красная нить

Одна непрерывная SVG-кривая (`path`, stroke `--thread`, 3px, лёгкая тень),
которая тянется через весь таймлайн и «пришпилена» к углам полароидов.
По мере скролла нить прорисовывается через `stroke-dashoffset`,
привязанный к прогрессу прокрутки (IntersectionObserver + rAF, без библиотек).
В финале нить сворачивается в форму сердца рядом с вердиктом —
это кульминация всей визуальной метафоры.

На мобильном нить идёт зигзагом по вертикали между фото; на десктопе
допустима более свободная «паутина». При `prefers-reduced-motion` нить
отображается сразу целиком, без анимации.

## Звук

- Два эффекта: «оттиск штампа» (короткий глухой удар) и «шорох бумаги»
  (при открытии дела / лайтбокса)
- Web Audio API, файлы ≤ 20 КБ каждый (mp3 + ogg), генерировать/подобрать
  свободные по лицензии
- Звук возможен только после первого взаимодействия пользователя
  (ограничение браузеров); в углу — маленькая кнопка mute, состояние
  запоминать в `sessionStorage`
- Громкость деликатная (≤ 0.4), эффекты не чаще одного в 300 мс

## Движение

- Один оркестрованный момент: открытие папки дела на первом экране
  (тесёмка развязывается → обложка «открывается» → скролл вниз)
- Полароиды появляются лёгким «прикалыванием» (translateY + поворот
  на 1–2° к финальному положению) при входе во вьюпорт
- Больше ничего: нить + появление фото + штампы. Никаких параллаксов
  на каждый чих — движение должно ощущаться рукой детектива, а не слайдером
