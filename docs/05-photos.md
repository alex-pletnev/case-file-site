# 05 — Фотографии и манифест

## Принципы

- Все фото хранятся **локально в репозитории**. Никаких ссылок на Instagram
  или другие внешние источники: они ломаются, тормозят и нарушают приватность.
- Владелец проекта сам скачивает фото со своих устройств и из Instagram
  своей девушки (со своего доступа) и кладёт их в `photos/source/`
  (папка-исходник, в деплой не идёт).
- Оптимизацию (ресайз в full/thumb, конвертацию в WebP) делает Claude Code
  скриптом или вручную — исходники не трогать.

## Формат photos/photos.json

```json
{
  "timeline": [
    {
      "id": "001",
      "file": "001-first-meeting",
      "date": "2023-05-14",
      "dateLabel": "14 мая 2023",
      "caption": "Первая встреча. Подозреваемая уже улыбалась.",
      "note": null,
      "rotate": -3
    },
    {
      "id": "002",
      "file": "002-coffee",
      "date": "2023-05-20",
      "dateLabel": "20 мая 2023",
      "caption": "Первое свидание. Улика приобщена к сердцу.",
      "note": "Подозреваемая действовала обдуманно: сначала улыбнулась.",
      "rotate": 2
    }
  ],
  "wanted": { "file": "wanted-portrait", "caption": "[Имя]" },
  "final": { "file": "final-photo", "caption": "Моя любимая улика" }
}
```

Поля:
- `file` — имя без расширения; код сам подставляет
  `thumb/<file>.webp` / `full/<file>.webp` (+ jpg fallback)
- `date` — ISO для сортировки; `dateLabel` — как показывать
- `caption` — рукописная подпись под полароидом (Caveat), она же основа alt
- `note` — если не null, после этого фото вставляется стикер-заметка
  следователя с этим текстом
- `rotate` — угол наклона полароида в градусах (задать заранее,
  чтобы раскладка была стабильной)

## Чек-лист подготовки фото (для владельца проекта)

1. Отобрать 20–40 фото, выстроить хронологию, вспомнить даты
   (хотя бы месяц — точность до дня не обязательна)
2. Переименовать по шаблону `NNN-slug.jpg` в порядке таймлайна
3. Придумать подпись к каждому фото — 1 тёплая строка
   (можно попросить Claude Code предложить варианты по описанию фото)
4. Выбрать «фото для ориентировки» (секция 2) и финальное фото (секция 5)
5. Положить всё в `photos/source/` и заполнить `photos.json`
