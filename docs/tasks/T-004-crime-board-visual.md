## Контекст

Задача заведена задним числом. По ходу сессии 15 июля пользователь дал серию
связанных запросов: улучшить визуал под референс crime-board с Pinterest,
исправить фон/рамку, переписать «нейрослоповые» тексты по 07-context-julia,
добавить параграфы к таймлайну, стикеры и вещдоки. Приоритет high —
день рождения 15.07.

Референс: https://i.pinimg.com/1200x/32/0d/d1/320dd18314ebcd71035531c5787b050a.jpg

## Acceptance criteria

- [x] Нить из прямой в паутину-зигзаг (свинги от 6% до 94% ширины) — работает на iPhone
- [x] Полароиды с расширенным rotation (±7°), пины на каждой карточке
- [x] Обложка: подвесная лампа с тёплым свечением
- [x] Деревянная рамка (градиент коричневых), 20/12px desktop/mobile
- [x] Фон-пробка: две текстуры + следы от пинов + боковой свет
- [x] Декорации: одинокие пины, скотч, обрывки бумаги
- [x] Тексты переписаны по антислоп-правилам (07-context-julia)
- [x] Буквица + рукописный финал в протоколе
- [x] Home-note: «Ты часто говоришь: «хочу домой». Дом — это мы»
- [x] 12 параграфов-историй под каждой точкой таймлайна
- [x] Стикеры-заметки следователя для 8 событий без них
- [x] Foreshadowing «хочу домой» в ориентировке
- [x] Секция «Вещдоки» между ориентировкой и хронологией
- [x] Пасхалка «Метод» в приписке следователя
